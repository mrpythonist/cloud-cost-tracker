## Getting help

If the docs do not answer your question:

1. Search the existing issues at
   https://github.com/mrpythonist/cloud-cost-tracker/issues to see if it
   has already been asked.
2. Open a new issue with the question template details: what you tried,
   what you expected, and the exact error or behaviour you saw. Include
   your environment (PHP version, Node version, Docker or local setup).
3. For bugs, use the bug report template. For feature ideas, use the
   feature request template.

Response times are best effort; this is a side project maintained by one
person.

## Security issues

Do not open a public issue for a security problem. See `SECURITY.md` for
how to report it privately.

## Commercial support

There is no commercial support offering for this project.
